# Workspace policy

`Roots-and-Relics-site-assets/` is a local, inspection-only reference directory.
Do not stage, commit, or push its contents to GitHub.

## Hosted logo assets

Production HTML must use the public Supabase URLs in `assets/logo-urls.json`.
Do not add local `Roots-and-Relics-site-assets/logos/` paths to site pages.

- Use `canonical.light` on dark or green backgrounds.
- Use `canonical.dark` on light backgrounds.
- Keep every supplied export in the registry, even when multiple exports are exact duplicates.
